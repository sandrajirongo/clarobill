# ClaroBill — Translations Review

**Status:** COMPLETED 2026-05-04 — review pass closed. Kept as historical record of the strings that shipped with i18n launch.

This file is for native-speaker review of the machine-translated onboarding strings.

**How to review:**
- Check each translated string against the English source.
- Pay particular attention to the medical/insurance terms marked **⚠ Review**.
- If a string is acceptable, leave it. If it needs changing, add your correction next to it.
- Return this file or send corrections to jirongo.sandie@gmail.com.

Terms that are kept in English intentionally: **Medicare, Medicaid, TRICARE, EOB, superbill, ZIP code** — these are proper names or US-specific terms with no standard translation.
